# ADR-0001 — PT-BR First + React + Phaser

## Status

**CANON / APPROVED**

## Decisão

- PT-BR first sempre em produto, documentação, UX, exemplos, mensagens e domínio.
- React como base da interface e aplicação.
- Phaser como base das experiências de jogo/interativas 2D.
- React + Phaser como arquitetura híbrida suportada.
- Componente composável como unidade fundamental.
- Simplicidade externa; complexidade interna.

## Critério

Todos os novos documentos, issues e implementações devem respeitar esta decisão.

## Próximo passo

Transformar o GoodProject Core Model em um sistema de componentes capaz de representar experiências React, Phaser e híbridas.
