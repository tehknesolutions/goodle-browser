# ADR-0002 — React + Phaser como base sintática unificada

## Status
**CANON / APPROVED**

React e Phaser são bases sintáticas e tecnológicas do Goodle, não dois produtos ou runtimes que o criador escolhe.

O criador cria em Goodle.

React fornece fundamentos para composição declarativa, componentes, propriedades, estado, eventos e interfaces.

Phaser fornece fundamentos para cenas, entidades, interação, animação, câmera, física e mundo 2D.

O Goodle possui sua própria camada de composição:

`Intenção → Composição Goodle → Manifestação → GoodRuntime → Experiência`

A manifestação pode utilizar React, Phaser ou ambos internamente. Essa escolha não é uma decisão de produto exposta ao criador.

**Uma linguagem Goodle. Uma composição Goodle. Uma experiência Goodle.**
