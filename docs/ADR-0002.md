# ADR-0002 — React + Phaser como base sintática unificada

## Status

**CANON / APPROVED**

React e Phaser não são dois produtos ou runtimes individuais que o criador precisa escolher. São **bases sintáticas e tecnológicas do Goodle**.

O criador cria em Goodle. O Goodle combina internamente padrões de composição declarativa de React com modelos de cena, entidade e interação de Phaser.

### React fornece a base para
- composição declarativa;
- componentes;
- propriedades;
- estado;
- eventos;
- composição de interfaces.

### Phaser fornece a base para
- cenas;
- entidades;
- mundo 2D;
- sprites;
- animações;
- física;
- câmera;
- entrada;
- loop e eventos interativos.

## Regra fundamental

O criador **não escolhe React ou Phaser**.

Ele descreve e compõe em Goodle.

O Goodle resolve como manifestar a composição.

## Modelo

`Intenção Goodle → Composição Goodle → Manifestação React/Phaser → GoodRuntime → Experiência`

## Consequência

Não criar dois produtos separados como “Goodle React” e “Goodle Phaser”.

Existe **um Goodle Runtime**, cuja manifestação utiliza as duas bases.

## Princípio

**Uma linguagem Goodle. Uma composição Goodle. Uma experiência Goodle.**
