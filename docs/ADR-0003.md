# ADR-0003 — Terceira base: Backend Goodle

## Status
**CANON / APPROVED**

O Goodle terá um terceiro fundamento tecnológico para fechar o tripé:

**React + Phaser + Backend**

Os três são fundamentos internos que o Goodle unifica em uma única experiência.

### React
Fundamentos de interface, composição declarativa, componentes, propriedades, estado e eventos.

### Phaser
Fundamentos de experiências interativas e 2D: cenas, entidades, animação, física, câmera e interação.

### Backend
Fundamentos de dados, lógica de servidor, persistência, autenticação, APIs, regras, tarefas e integrações.

## Regra fundamental

O criador não precisa decidir frontend, jogo ou backend. Ele cria **Goodle**.

O Goodle transforma a intenção em uma composição única que pode conter interface, experiência interativa e serviços de backend.

## Tripé

`Goodle = Interface + Experiência + Backend`

Manifestado internamente por:

`React + Phaser + Backend`

## Objetivo

Fechar o ciclo de criação para que um projeto possa sair de uma intenção e chegar a uma aplicação funcional completa sem exigir que o criador domine três stacks diferentes.

## Princípio

**Uma linguagem. Uma composição. Um projeto. Um ecossistema.**
