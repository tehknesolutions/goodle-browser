# ADR-0004 — TypeScript como linguagem-base do tripé

## Status
**CANON / APPROVED — linguagem**

TypeScript é a linguagem-base do Goodle.

Isso não significa que o criador precise escrever TypeScript. Significa que a manifestação técnica do ecossistema pode compartilhar uma linguagem entre:

- React;
- Phaser;
- Backend.

## Objetivo

Reduzir a quantidade de linguagens que o GAIC e o sistema de criação precisam dominar e manter.

## Camadas

```
Intenção
   ↓
GoodProject
   ↓
Vibe / Low / Block
   ↓
Manifestação Goodle
   ↓
TypeScript
   ├── React
   ├── Phaser
   └── Backend
```

## Runtime de backend

O runtime ainda não é canônico.

Deno, Bun e Node.js serão comparados por prova técnica registrada na Issue #22.

Portanto:

**TypeScript = decisão de linguagem.**

**Deno/Bun/Node = decisão de runtime ainda experimental.**
