# Backend Goodle — Fundação

## Papel

O Backend Goodle é a terceira base do tripé:

- dados;
- persistência;
- usuários;
- autenticação;
- autorização;
- APIs;
- regras de servidor;
- tarefas;
- arquivos;
- eventos;
- integrações;
- notificações.

## Abstração

O criador trabalha com componentes e serviços Goodle.

Exemplo:

`Usuário + Perfil + Banco + Pontuação + Ranking`

O Goodle resolve a manifestação de backend.

## Não expor complexidade

O usuário não precisa começar sabendo rotas, controladores, ORM, SQL, infraestrutura, filas ou servidores.

## Progressive disclosure

A interface começa simples. Quando necessário, o criador pode abrir propriedades avançadas, regras, blocos, código e configurações de infraestrutura.

## Segurança

Capacidades de backend passam pelo modelo de capacidades do Goodle. Nenhum projeto recebe acesso irrestrito por padrão.

## Decisão atual

A função arquitetural do Backend é canônica. A tecnologia concreta ainda será escolhida por prototipagem e critérios técnicos.
