# Modos de Criação Goodle

## Uma máquina, três portas

### Vibe-coding
O criador descreve o que quer. O GAIC interpreta a intenção e produz uma composição Goodle.

### Low-code
O criador manipula componentes, propriedades, dados, eventos e relações.

### Block-code
O criador monta lógica visualmente com blocos.

### Código avançado
O criador pode acessar a implementação quando quiser maior controle.

## Mesma representação

Todos os modos editam o mesmo `GoodProject`.

```
                 GoodProject
                /     |      \
          Vibe       Low      Block
        coding      code      code
             \       |       /
              \      |      /
               mesma representação
                      │
                    Código
```

## Regra

Trocar de modo nunca deve exigir reconstrução do projeto.

O usuário pode começar com:

> “Crie um jogo de plataforma.”

Depois editar componentes.

Depois abrir os blocos.

Depois editar código.

Tudo continua sendo o mesmo projeto.
