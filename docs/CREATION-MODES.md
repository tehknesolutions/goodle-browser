# Modos de Criação Goodle

## Uma máquina, três portas

### Vibe-coding
O criador descreve o que quer. O GAIC interpreta a intenção, propõe a composição, cria componentes e executa a experiência.

### Low-code
O criador manipula componentes, propriedades, dados, eventos e relações.

### Block-code
O criador monta lógica visualmente com blocos.

Exemplo:

`Quando → Condição → Ação → Caso contrário`

## Mesma representação

Os três modos operam sobre o mesmo `GoodProject`.

```
                 GoodProject
                /     |      \
          Vibe       Low      Block
        coding      code      code
                \     |     /
                 mesma máquina
```

Código tradicional pode existir como camada avançada de escape.

## Progressão

`Intenção → Componentes → Blocos → Código`

O usuário pode aprofundar sem reconstruir o projeto.
