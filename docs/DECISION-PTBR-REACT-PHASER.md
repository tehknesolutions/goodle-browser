# Decisão Arquitetural — PT-BR First + React + Phaser

## Status

**CANON / APPROVED**

## Decisões

1. Goodle é **PT-BR first sempre**.
2. React é a base principal da camada de interface e aplicação.
3. Phaser é a base principal das experiências de jogo e interativas 2D.
4. React e Phaser devem poder coexistir em experiências híbridas.
5. O componente composável é a unidade fundamental de criação.
6. O objetivo é permitir **criar coisas complexas com composição simples**.
7. A complexidade deve ficar predominantemente na implementação interna, não na experiência do criador.
8. Novas tecnologias não entram no núcleo sem demonstrar ganho claro de capacidade ou redução de complexidade.

## Consequência

Arquitetura, PDD, GDD, componentes, exemplos, backlog e decisões devem respeitar esta base.
