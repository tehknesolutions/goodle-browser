# GAIC — Goodle AI Creation/Intelligence Coordinator

## Role

GAIC is the orchestration layer between human intention and Goodle execution.

## Pipeline

1. Capture intent.
2. Resolve ambiguity.
3. Build project model.
4. Propose execution plan.
5. Request required capabilities.
6. Delegate specialized work.
7. Execute in bounded steps.
8. Validate outputs.
9. Repair failures.
10. Record events and provenance.
11. Produce artifacts.

## Specialist roles

- Architect
- Product Designer
- UX/UI Designer
- Engineer
- Game Designer
- Asset Director
- QA/Validation
- Security
- DevOps/Release

These are roles, not necessarily separate models.

## Human gates

Human approval should be required for:
- destructive changes
- capability escalation
- publishing
- canonical project decisions
- major architecture changes

## Anti-rework rule

Before modifying a validated area, GAIC must inspect its current state, dependencies and prior decisions.
