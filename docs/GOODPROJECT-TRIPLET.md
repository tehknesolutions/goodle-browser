# GoodProject — Tripé Unificado

```
             GOODPROJECT
                  │
       ┌──────────┼──────────┐
       │          │          │
     REACT      PHASER    BACKEND
       │          │          │
       └──────────┼──────────┘
                  │
            GOOD RUNTIME
                  │
             EXPERIÊNCIA
```

React, Phaser e Backend não são três projetos. São partes de uma única manifestação.

Um componente pode atravessar o tripé. Por exemplo, `Personagem` pode possuir visual, estado, controles, dados persistentes, regras de servidor, eventos e sincronização.

O criador continua vendo apenas **Personagem**.

## Estrutura

```
GoodProject
├── Interface
├── Experiência
├── Dados
├── Lógica
├── Eventos
├── Regras
├── Serviços
├── Estado
└── Ativos
```
