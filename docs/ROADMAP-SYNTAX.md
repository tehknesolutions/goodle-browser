# Roadmap — Sintaxe Goodle

## S0 — Fundação
- modelo de expressão;
- fluxos;
- dados;
- regras;
- composição.

## S1 — Leitor declarativo
- [x] evento inicial;
- [x] ações;
- [x] representação estruturada;
- [x] erros básicos.

## S2 — Editor de intenção
Converter linguagem natural em estrutura Goodle.

## S3 — Editor low-code
Manipular componentes e propriedades.

## S4 — Editor block-code
Representar eventos, condições e ações visualmente.

## S5 — Condições e dados
Adicionar variáveis, comparações, condições e referências.

## S6 — Manifestação TypeScript
Gerar/atualizar a manifestação técnica sem quebrar a representação Goodle.

## S7 — Sincronização bidirecional
Intenção, componentes, blocos e código devem permanecer sincronizados quando possível.

## S8 — Validação
Detectar conflitos, referências inválidas, tipos incompatíveis e capacidades insuficientes.

## S9 — Runtime
Executar a composição completa através do GoodRuntime.
