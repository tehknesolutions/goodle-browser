# Goodle Roadmap

## G0 — Foundation

- GoodProject model
- Intent model
- OldRewrite parser/interpreter
- OldTable model
- minimal GoodRuntime
- preview surface
- event log
- artifact registry
- persistence

## G1 — GAIC

- plan generation
- project synthesis
- repair loop
- validation orchestration
- specialist roles

## G2 — Durable Creation

- HEPGA packaging
- revision history
- provenance graph
- conflict detection
- import/export

## G3 — Secure Execution

- Capability Broker
- scoped tools
- permission UX
- audit trail
- sandboxed execution

## G4 — Goodle Browser / Studio

- browser shell
- project workspace
- creation console
- runtime preview
- debugging
- artifact browser

## G5 — Advanced Runtime

- multi-target runtime
- advanced rendering
- performance tooling
- UltraRender research/implementation

## Rule

Roadmap ordering is an implementation proposal, not a claim that later features are impossible earlier.
