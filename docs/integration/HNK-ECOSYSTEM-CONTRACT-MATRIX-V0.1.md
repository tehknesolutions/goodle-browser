# HNK Ecosystem Contract Matrix V0.1

| Domain | Upstream authority | Goodle consumes | Goodle must not redefine |
|---|---|---|---|
| HNK canon | CODEX-HNK | canonical contracts, registry references | HNK canon |
| HNK language | HNK-KODE | Semantic IDs, grammar/profile contracts | HNK-KODE semantics |
| Execution framework | haKodan | AST/HOM/HNK-IR/manifestation contracts | haKodan runtime semantics |
| Worlds | HNK-VERSE | consumer/SDK contracts | Verse runtime authority |
| Technology memory | TKN-OS | provenance, know-how, registry projections | institutional authority |
| Creation process | GIP/TKN Intelligence | plans, validation, human gates | authorization semantics |
| Goodle implementation | Goodle | own IR/runtime/UI contracts | upstream canon |

## Core invariants

1. Integration is not absorption.
2. Projection is not authority.
3. Source identity is preserved.
4. Unknown semantics remain unresolved.
5. Canon promotion requires an explicit human gate.
6. Security-critical ambiguity fails closed.
7. Historical records are append-only/correction-based.
8. Semantic IDs survive language and target changes.
