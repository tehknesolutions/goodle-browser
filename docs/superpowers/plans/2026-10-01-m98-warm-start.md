# M98 — Contact Manifold Warm Start

## Canonical contract

M98 extends the M97 manifold cache with persistent normal and tangential impulse state. A warm-start operation may reuse this state only when the manifold remains coherent under the M96/M97 pair and AABB signatures.

`fisica.warm_start` enables automatic warm-start participation in subsequent solver calls. `fisica.warm_start_aplicar` explicitly applies all coherent cached impulses in deterministic pair order. `fisica.warm_start_estado` exposes the active state and cached impulses.

Warm start is an optimization/state reuse layer. M86/M88 remain authoritative for collision confirmation, and M96/M97 remain authoritative for coherence/invalidation.

## Acceptance

- first contact has no stale warm-start state;
- confirmed persistent contacts retain normal/tangential impulse state;
- coherent state can be reused;
- changed/disappeared pairs are not reused;
- explicit M96 invalidation clears warm-start state;
- deterministic pair order;
- observable/serializable state;
- no external engine dependency.
